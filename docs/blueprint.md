# **App Name**: ScholarAI

## Core Features:

- Essay Checker: Paste or upload essays, and the AI tool reviews them for grammar, clarity, and structure using an LLM. The LLM is the main decision-making module.
- Smart Notes: Record audio notes, transcribe them using AI, and organize them with categories, timestamps, and tags.
- AI Flashcards: Highlight key text or upload study material, and the AI automatically generates flashcards.
- Video Study Assistant: Paste YouTube or video links; the AI tool transcribes and summarizes the content, extracting notes and key points. The LLM is the main decision-making module.
- Image Analyzer: Upload images (diagrams, notes, slides), and the AI describes or extracts text from them.  The LLM is the main decision-making module.
- Text-to-Image Generator: Create educational images or doodles based on text prompts using AI.
- Chat Assistant: Study chatbox using an LLM to answer academic or research questions.

## Style Guidelines:

- Primary color: Light desaturated blue (#A7C4D6) evoking a sense of calmness and focus, inspired by a traditional academic environment.
- Background color: Very light desaturated blue (#F0F4F7) for a clean, uncluttered backdrop that is easy on the eyes.
- Accent color: Muted purple (#958AA6) to highlight interactive elements, providing contrast without overwhelming the user.
- Body text: 'Inter', a sans-serif font for a modern and neutral look suitable for long blocks of text.
- Headline font: 'Space Grotesk', a sans-serif font that adds a slightly techy, modern edge, used for headlines.
- Use minimalist icons that clearly represent each function (e.g., a pen for essay check, a microphone for notes).
- Sidebar navigation for primary tools, ensuring easy access to core features on every page.
- Subtle transitions and animations to create a smooth and engaging user experience.
